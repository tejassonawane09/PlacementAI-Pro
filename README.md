# 🎓 PlacementAI Pro – Smart Job Placement Prediction System

PlacementAI Pro is an advanced Machine Learning web application that predicts student placement probability using academic performance, internships, projects, aptitude score, certifications, and soft skills.

The project is built with **Python, Scikit-learn, Streamlit, and Plotly** and provides a modern AI-powered dashboard with analytics and career guidance.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/PlacementAI-Pro.git
```

Move into project folder:

```bash
cd PlacementAI-Pro
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```
